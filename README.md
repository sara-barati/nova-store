# NOVA Store

A responsive e-commerce web application built with **Next.js, React, and TypeScript** as part of a frontend technical assignment.

NOVA Store provides a bilingual shopping experience with product discovery, filtering, sorting, product details, and shopping cart management.

## Features

### Products

- Fetch product data from Fake Store API
- Browse the product catalog
- Search products by title
- Filter products by category
- Sort products by price, popularity, and rating
- Paginate product listings
- View individual product details

### Shopping Cart

- Add products to the cart
- Remove products from the cart
- Update product quantities
- Persist cart data using Zustand and Local Storage

### User Interface

- Persian and English language support
- Right-to-left (RTL) and left-to-right (LTR) layouts
- Light and dark themes
- Responsive layout for different screen sizes
- Toast notifications

## Tech Stack

| Technology        | Purpose                                 |
| ----------------- | --------------------------------------- |
| Next.js           | React framework and application routing |
| React             | User interface                          |
| TypeScript        | Static typing                           |
| Styled Components | Component-based styling and theming     |
| Zustand           | Client-side state management            |
| Axios             | HTTP requests                           |
| next-intl         | Internationalization                    |
| Lucide React      | Icons                                   |
| Sonner            | Toast notifications                     |
| Fake Store API    | Product data source                     |
